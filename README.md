## لماذا هذا المشروع؟

في عالم مليء بالضوضاء، أردتُ أن يكون هناك مكان هادئ وجميل —  
مكان تقرأ فيه عن سيرة خير البشر ﷺ بتجربة تليق بعظمته.

لا كتب PDF جافة. لا صفحات ممتلئة بالإعلانات.  
فقط سيرة، وتصميم، وروح.

## ما الذي ستجده هنا؟

<br/>

📅 &nbsp; **التسلسل الزمني** — خط زمني تفاعلي لأحداث السيرة كاملةً من المولد حتى الوفاة

⚔️ &nbsp; **غزواته ﷺ** — توثيق كامل للغزوات مع محاكاة حية للمعارك

👑 &nbsp; **أمهات المؤمنين** — تراجم وافية لزوجاته الكريمات بأسلوب راقٍ

✨ &nbsp; **معجزاته ﷺ** — المعجزات الحسية والمعنوية موثقةً بمصادرها

📖 &nbsp; **خطبة الوداع** — النص الكامل مع التحليل، كلمات غيّرت التاريخ

🔮 &nbsp; **نبوءاته ﷺ** — نبوءات تحققت عبر القرون مع الشواهد

🌳 &nbsp; **شجرة النسب الشريف** — النسب الكريم تفاعلياً حتى آدم عليه السلام

🗺️ &nbsp; **رحلة الهجرة** — كل محطة في الرحلة المباركة بتفاصيلها

👥 &nbsp; **الصحابة الكرام** — مشاهير من رافقوا النور وحملوه للعالم

🛡️ &nbsp; **السرايا العسكرية** — السرايا التي أرسلها ﷺ خارج قيادته المباشرة

📛 &nbsp; **أسماؤه ﷺ** — أسماؤه الشريفة ومعانيها العظيمة

❓ &nbsp; **اختبر نفسك** — كم تعرف عن حياة خير البشر؟

<br/>

## كيف يبدو؟

خلفيات كالليل، ونصوص كالذهب.  
حركات سلسة تصحبك من حدث لحدث.  
وضع قراءة يحوّل الصفحة إلى ورقة كريمية هادئة.  
بحث فوري يوصلك لأي حدث أو اسم أو معركة في ثوانٍ.

## المبني عليه

| | |
|---|---|
| **Next.js 16** | App Router — 86 صفحة مُولَّدة مسبقاً |
| **React 19** | لأن التفاعل جزء من التجربة |
| **Tailwind CSS v4** | تصميم من الصفر بنكهة إسلامية |
| **Framer Motion** | كل حركة لها معنى |
| **TypeScript** | لأن الكود كالكلام، يجب أن يكون دقيقاً |
| **Vercel** | نشر فوري مع كل تحديث |

## للمطورين

```bash
git clone https://github.com/SaadHASSON1/Noor-Alnubuwwah.git
cd Noor-Alnubuwwah/nextapp
npm install --legacy-peer-deps
npm run dev
```

> أضف `NEXT_PUBLIC_MAPBOX_TOKEN` في `.env.local` لتفعيل الخرائط
